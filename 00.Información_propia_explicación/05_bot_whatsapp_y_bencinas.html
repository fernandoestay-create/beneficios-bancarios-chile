Detalles Tecnicos

Estado conversacional

user_flow = {}
# Estructura por usuario:
# {
#   "+56912345678": {
#     "step": "ask_tipo" | "ask_dia" | "ask_banco" | "resultado",
#     "tipo": "restaurantes" | "bencinas",
#     "dia": "lunes",
#     "bancos": ["BCI", "Scotiabank"],
#   }
# }

Se mantiene en memoria (se pierde si el servidor reinicia). Cada usuario tiene su propio estado.

Seleccion de multiples bancos

  • El bot muestra una lista numerada de bancos
  • El usuario puede seleccionar multiples bancos separando numeros con coma: "1,2,4"
  • Tambien acepta "todos" para ver todos los bancos
  • Los bancos seleccionados se pasan como parametros URL multiples: ?banco=BCI&banco=Scotiabank

Generacion del link

  • El link lleva directamente a la pagina con filtros pre-aplicados
  • Restaurantes: /ver?dia=X&banco=Y&banco=Z
  • Bencinas: /ver/bencinas?dia=X
  • Al abrir el link, la pagina aplica automaticamente los filtros de la URL

Sin dependencias externas de IA

  • No se usa OpenAI (ni GPT ni embeddings) en el flujo de WhatsApp
  • No se usa Pinecone en el flujo de WhatsApp
  • Todo el filtrado y formato se hace en Python puro
  • El endpoint /rag sigue disponible en la API para otros usos
