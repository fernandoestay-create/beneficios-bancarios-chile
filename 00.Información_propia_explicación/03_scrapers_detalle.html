Scraper de Bencinas

ScraperBencinas

Archivo: scrapers.py

Cadenas scrapeadas: Copec, Shell, Aramco

Datos extraidos por descuento:

  • id - identificador unico
  • cadena - "Copec", "Shell", "Aramco"
  • banco - banco o medio de pago asociado
  • tarjeta - tarjeta o app especifica
  • descuento_por_litro - monto en $ por litro
  • descuento_texto - texto legible del descuento
  • dias_validos - dias de la semana
  • condicion - condiciones especiales
  • tope_litros - limite de litros
  • tope_monto - limite de monto
  • combustible - tipo de combustible
  • vigencia_mes - mes de vigencia ("2026-03")
  • url_fuente - link a la pagina del descuento

Estaciones: de OpenStreetMap a la CNE (cambio de v_03)

Historico (v_02, marzo 2026): las estaciones se consultaban a la Overpass API de OpenStreetMap y se obtenian 367 puntos de Copec, Shell y Aramco. Eso ya no es asi: esa API resulto inestable y devolvia 0 estaciones cuando corria en la nube (timeouts).

Hoy las estaciones y los precios vienen de la API publica de la Comision Nacional de Energia (bencinaenlinea.cl): 1.821 estaciones de todo Chile con precio real por combustible, de las cuales 1.470 son de Copec, Shell o Aramco. El detalle completo esta en Precios Combustible.

Los descuentos, en cambio, no se scrapean: se curan a mano desde la fuente oficial de cada cadena y cada dato lleva su confianza y su url_fuente. Al guardar, el sistema preserva lo curado para que un re-scrape no lo pise.

OrquestadorScrapers

Comunas RM extraidasDetecta "Providencia" de la direccion
Textos limpiosElimina HTML, "dto" -> "dcto", trunca
