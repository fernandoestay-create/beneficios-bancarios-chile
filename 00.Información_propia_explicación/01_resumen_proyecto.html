Descripcion General

Sistema completo de web scraping y analytics que extrae ofertas de descuento de bancos chilenos (15 scrapers, 14 bancos activos; BancoEstado sigue diferido porque su campana no existe) (restaurantes y otros rubros) y 3 cadenas de bencina (Copec, Shell, Aramco), exponiendo los datos - todos trazables a su fuente oficial - a traves de:

  • Pagina web de restaurantes (/ver) - filtros interactivos, tarjetas, mapa Leaflet
  • Pagina de otros beneficios (/ver/beneficios) - retail, viajes, salud y entretencion, solo ofertas verificables
  • Pagina web de bencinas (/ver/bencinas) - hero cards con fotos, logos SVG, estaciones reales
  • Pagina de cuotas sin interes (/ver/cuotas) - campanas por banco y categoria
  • Bot WhatsApp + Telegram - menu guiado sin IA (4 opciones: restaurantes, bencinas, cuotas, otros beneficios), $0 costo
  • API REST - endpoints JSON para consultar beneficios programaticamente

Trazabilidad de Datos NUEVO

Principio agregado en agosto 2026: toda la data de cara al usuario debe venir de una fuente oficial marcada, nunca de un agregador sin verificar. Cada dato lleva un campo confianza (oficial / secundaria) y su url_fuente - un agregador de terceros sirve solo como control de calidad, no como fuente de verdad. Los descuentos de bencina se re-curaron completos desde las paginas oficiales de cada cadena.

Criterio aplicado en toda la web: "si no esta chequeado, mejor no mostrar". Cuando falta un dato verificado, la pagina muestra "Estamos confirmando descuentos" en vez de un dato dudoso. Una guardia de madrugada (revision automatica diaria, ~03:00 Chile, en GitHub Actions - gratis y sin computador prendido) tiene 7 guards que MIDEN contra la fuente real de cada banco: paginas y seguridad, trazabilidad, y ahora tambien los dias y la region (vs. la API del banco), % absurdos, frescura de datos y nombres genericos. Avisa por correo solo si algo reaparece. Es la Capa 1 de la "prueba acida siempre"; la Capa 2 es una auditoria con IA mensual que busca errores nuevos, y cada hallazgo se vuelve un guard permanente de la Capa 1.

Stack Tecnologico

Backend: Python 3.9+ / FastAPI / Uvicorn
Scraping: requests / BeautifulSoup / lxml
Frontend: HTML/CSS/JS embebido en f-string Python
Mapas: Leaflet + CARTO tiles
Estaciones y precios: API publica de la CNE, bencinaenlinea.cl (1.821 estaciones con precio). Sustituyo a OpenStreetMap en v_03
Bot: Twilio WhatsApp API + Telegram Bot API
Logos: 13 SVG locales + 3 fotos JPG (/static/logos/)
Deploy: VPS propio (Contabo, systemd cartera.service tras Caddy) — Render suspendido 2026-08-23
