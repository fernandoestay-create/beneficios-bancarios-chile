Flujo 1: Scraping Restaurantes

python scrapers.py
  |-- ScraperBancoChile()     -> API CMS          -> ~200 Beneficio
  |-- ScraperBancoFalabella() -> API CMS v2       -> ~150 Beneficio
  |-- ScraperBCI()            -> HTML + regex      -> ~100 Beneficio
  |-- ScraperItau()           -> API JSON          -> ~50 Beneficio
  |-- ScraperScotiabank()     -> JS embebido       -> ~61 Beneficio
  |-- ScraperSantander()      -> HTML              -> ~80 Beneficio
  |-- (9 scrapers mas...)
  |
  v
OrquestadorScrapers._normalizar_todos()
  |-- Fechas:     "31 de marzo 2026" -> "31-Mar-2026"
  |-- Regiones:   "santiago", "rm"   -> "Metropolitana"
  |-- Comunas:    extraer de direccion para RM
  |-- Descuentos: "50% de descuento" -> "50% dcto."
  |
  v
beneficios.json (985 beneficios) + beneficios.csv

Flujo 2: Scraping Bencinas (NUEVO v_02)

scrapers.py -> ScraperBencinas
  |

Flujo 3: Bot WhatsApp v2

Usuario envia mensaje (cualquiera)
  |
  v
Twilio -> POST /webhook (api.py)
  |
  v
"Restaurantes o Bencinas?"
  |
  +-- BENCINAS (2 pasos):
  |     Paso 1: "Que dia?" -> lunes/martes/.../hoy/todos
  |     Paso 2: RESULTADO
  |       - Filtra descuentos por dia
  |       - Genera link: /ver/bencinas?dia=lunes
  |
  +-- RESTAURANTES (3 pasos):
        Paso 1: "Que dia?" -> lunes/martes/.../hoy/todos
        Paso 2: "Que banco(s)?" -> lista numerada, seleccion: "1,2,4"
        Paso 3: RESULTADO
          - Filtra por dia + banco(s)
          - Genera link: /ver?dia=lunes&banco=BCI&banco=Scotiabank
  |
  v
Twilio envia respuesta + link al usuario
(Sin OpenAI, sin Pinecone, $0 costo IA)

Flujo 4: Pagina Web Restaurantes (/ver)

GET /ver?banco=BCI&banco=Scotiabank&dia=miercoles
  |
  v
api.py genera HTML completo (f-string)
  |-- Python: serializa beneficios -> JSON embebido en script
  |-- Python: lee URL params (banco, dia) para pre-filtrar
  |-- HTML: hero + sidebar filtros + main contenido
  |-- CSS: estilos embebidos (variables CSS, responsive)
  |-- JS: logica de filtros, rendering, mapa, Multi-Select (MS)
  |
  v
Navegador recibe HTML completo
  |-- JS: pre-aplica filtros de URL params (multi-banco)
  |-- JS: render() filtra deals y genera cards
  |-- JS: Leaflet inicializa mapa con markers
  |-- JS: summary bar con logos clickeables

Flujo 5: Pagina Web Bencinas (/ver/bencinas) - NUEVO v_02

GET /ver/bencinas?dia=lunes
  |
  v
api.py genera HTML con:
  |-- Hero cards: foto estacion de fondo + logo cadena SVG
  |-- Descuentos agrupados por cadena (Copec, Shell, Aramco)
  |-- Filtro por dia (pre-aplicable desde URL)
  |-- Estaciones reales en mapa Leaflet (367 markers con lat/lon)
  |-- Logos servidos desde /static/logos/ (SVG locales)

Deploy en Produccion

Render.com

  • Servicio principal: api-beneficios-chile - FastAPI + Uvicorn
  • Build: pip install -r requirements.txt
  • Start: uvicorn api:app --host 0.0.0.0 --port $PORT
  • Auto-deploy: push a main en GitHub
  • Servicio secundario: whatsapp-bot-beneficios (Flask alternativo)

Variables de entorno

  • OPENAI_API_KEY - solo para endpoint /rag (ya no usado en WhatsApp)
  • PINECONE_API_KEY, PINECONE_HOST, etc. - para RAG API
