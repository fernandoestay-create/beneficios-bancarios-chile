1. Problema resuelto

Antes (v_02): OpenStreetMap Overpass API

  • Fuente: OpenStreetMap (datos voluntarios, sin precios)
  • Resultado: 0 estaciones en GitHub Actions (API inestable, timeouts)
  • Solo ubicaciones, sin precios de combustible
  • Solo Copec/Shell/Aramco (367 max cuando funcionaba)

Ahora (v_03): bencinaenlinea.cl (CNE)

  • Fuente: API publica de la Comision Nacional de Energia
  • Resultado: 1,470 estaciones de todo Chile
  • Precios reales: 93, 95, 97, Diesel, Kerosene
  • 120+ marcas (no solo las 3 principales)
  • Endpoint: GET https://api.bencinaenlinea.cl/api/busqueda_estacion_filtro
  • Sin autenticacion, sin limite de requests

2. Scraper: ScraperBencinaEnLinea

Clase en scrapers.py

Reemplaza ScraperEstacionesCNE (Overpass API). Obtiene todas las estaciones de Chile con precios.

ScraperBencinaEnLinea
  ├── _cargar_marcas()     → GET /api/marca_ciudadano (120 marcas)
  ├── _scrapear_estaciones() → GET /api/busqueda_estacion_filtro (1,817 raw)
  ├── _extraer_precios()   → Mapea combustibles: 93, 95, 97, Diesel, Kerosene
  └── _normalizar_cadena() → Copec, Shell, Aramco, Petrobras, etc.

Modelo EstacionBencina (ampliado)

5. Pagina /ver/bencinas — 3 vistas

VistaContenido
TarjetasCards de descuentos bancarios con fotos, logos, dias, detalles
Mapa1,470 estaciones con logos de cadena + precios en popups + boton "Ir"
PU BencinaComparador de precios: mapa con marcadores logo+precio, ranking sincronizado con viewport

Funcionalidades PU Bencina

  • Mapa con marcadores: logo cadena + precio (verde=barato, rojo=caro)
  • Ranking de las 50 mas baratas en la zona visible del mapa
  • Al mover/zoom el mapa, el ranking se actualiza automaticamente
  • Stats en tiempo real: mas barato, mas caro, promedio, total en vista
  • Filtros combustible: 93 / 95 / 97 / Diesel / Kerosene
  • Boton "Ir" en cada estacion (abre Google Maps con direccion)
  • Geolocalizacion "Mi ubicacion" (centra mapa en tu posicion)
  • Cadenas sin logo muestran badge con nombre de color

6. Filtros compartidos (sidebar)

El sidebar izquierdo aplica a las 3 vistas por igual:

  • Buscar: texto libre
  • Banco/App: multi-select
  • Dia: chips L M X J V S D
  • Cadena: Todas / Copec / Shell / Aramco / Otras (nuevo v_03)
  • Region: dropdown (Metropolitana siempre primero). Al seleccionar, ambos mapas se centran
  • Comuna: dinamico segun region seleccionada
  • Limpiar filtros: resetea todo incluyendo filtros de PU Bencina
